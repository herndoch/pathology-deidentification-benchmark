# Detailed synthetic lung illustration

Two newly authored reports describe a fictional lung core biopsy and linked EGFR molecular testing. Patient details, dates, specimen measurements, allele fractions, coverage, and assay parameters are invented for illustration. This is not an additional benchmark cohort or an independently validated clinical report.

The transcript and T790M nomenclature were checked against [NCBI ClinVar](https://www.ncbi.nlm.nih.gov/clinvar/RCV000557450.4/). The lung EGFR context is supported by the [FDA companion diagnostic table](https://www.fda.gov/medical-devices/in-vitro-diagnostics/list-fda-authorized-companion-diagnostic-devices-in-vitro-and-imaging-tools). No therapeutic recommendation or validation claim is made.

`inputs.json` is the frozen source text. `outputs.json` contains exact newly computed masks from the unchanged institution-developed pipeline, context-aware rules, and refined rules. No hosted LLM was run on this illustrative case. Eight full-size JPEGs show all original/output combinations; the six-panel collage shows original, institution-developed, and refined methods.

EGFR p.T790M and p.L858R are useful molecular findings to retain. Names and medical-record numbers are identifying fields to mask. Colored highlighting does not alter source text or saved output. The examples are excluded from all quantitative denominators.
